# 개인 메일 통합 문의함

상태: 로컬 구현. 운영 migration·배포·실제 Google/Naver 인증 미실행.

## 접근 범위

- 기존 문의 탭 승인 계정(본인·박석영 팀장) 제한 유지. 다른 직원·외부 계정으로 공개 범위를 넓히지 않는다.
- 홈페이지 문의·공간등록·대관 원본은 기존 두 담당자가 공유한다.
- 메일 연결·메일 사본·다음 연락 일정은 연결한 ERP 사용자 본인만 조회한다. 관리자 역할도 타인의 메일을 조회할 API가 없다.
- 비밀값은 AES-GCM 암호문으로만 서버 DB에 저장한다. 클라이언트 조회 DTO·로그에는 토큰/앱 비밀번호를 반환하지 않는다.
- 신규4테이블 RLS 활성화, 공개 API 정책 없음. 서버의 기존 DB 역할만 이용한다.

## 사용 순서

1. 승인 후 `20261113090000_private_inbox` migration과 운영 배포 적용. 기존 미배포 이메일 알림 migration도 순서대로 적용된다.
2. 문의 → 통합 보기 → 내 메일 연결.
3. Gmail: 먼저 Gmail에 `ERP문의` 라벨을 만들고 필요한 메일에 지정. 라벨명을 입력하고 Google 연결 버튼에서 계정 선택·읽기 권한 동의. 한 사용자가 여러 계정을 연결할 수 있다.
4. Google OAuth 프로젝트에서 Gmail API가 활성화되어야 한다. 기존 Google 클라이언트의 등록된 `/api/admin/drive-callback` URI를 분기해서 쓰며 Drive/알림 발송 토큰을 덮어쓰지 않는다. 새 Gmail 읽기 scope는 제한 scope이므로 Google 앱 게시 상태/테스트 사용자/검증 정책을 확인한다. 권한 자체는 전체 메일 읽기지만 애플리케이션 수집은 지정 라벨만이다.
5. 네이버: PC 메일 설정에서 IMAP 사용, 네이버ID 2단계 인증 후 앱 비밀번호 생성. 일반 비밀번호가 아닌 앱 비밀번호를 ERP 입력란에 직접 입력. 사용자 지정 메일함 또는 `INBOX` 선택.
6. 연결된 계정의 **수신** 버튼으로 가져오기. 자동으로 메일을 발송하거나 원본 읽음 상태를 바꾸지 않는다. 현재 버전은 백그라운드 메일 수집 예약이 아니라 명시적인 수신 버튼 방식이다. 화면의 저장 사본/연락 일정은 보이는 탭에서만60초 갱신한다.
7. 원문 선택 → 내 다음 연락 일정에 KST 일시와 메모 입력 → 저장. 일시 미정이면 비워 둔다. 알림·자동 발송은 제공하지 않는다.

## 수집/저장 제한

- 최근30일, 지정 라벨/메일함의 최근40건/수신. 화면은 최신200건. 계정 최대10개.
- Gmail 본문은 text/plain만 표시. HTML·추적 이미지·첨부파일은 브라우저에 표시하거나 자동 다운로드하지 않는다.
- 네이버는 TLS 고정 서버 `imap.naver.com:993`, readOnly 메일함. 원문2MB를 넘는 메일은 건너뛰며 텍스트 본문만 최대20,000자 저장. 원본 메일 보존.
- 외부 동기화 타임아웃, 계정별DB리스와60초 쿨다운, provider message ID 고유 제약으로 중복 저장 방지.
- 폴더를 바꾸면 이전 범위 사본과 해당 일정 제거. 연결 해제 시 ERP 사본·일정을 제거하고 원본 메일은 유지. Google 권한 자체 철회는 Google 계정의 연결된 앱에서 가능.
- 웹사이트 일정 키는 행번호가 아닌 기존 접수 identity 해시. 일정 수정은 version 비교로 오래된 화면의 덮어쓰기를 차단한다.

## 확인 범위와 남은 작업

- 서비스 단위 검증: 인증 실패 시 DB 접근 없음, 조회 본인 필터, 타인 메일 일정/연결 해제 차단, 버전 충돌, 중복 동기화 리스, 폴더 변경 정리, KST 파싱.
- 실제 메일 인증·수신은 사용자 직접 동의/앱 비밀번호 입력 후 별도 검증해야 한다. 실제 DB 저장·동시성 검증은 미적용 migration 이후 별도 격리 DB에서 필요.
- 가상 자료 UI 검증은 운영 DB·메일 서버를 호출하지 않는다. 캡처는 연결 완료나 실수신 성공 증거가 아니다.

공식 안내: [Gmail scope](https://developers.google.com/workspace/gmail/api/auth/scopes), [Naver 외부 메일 인증](https://help.naver.com/service/30029/contents/24347).

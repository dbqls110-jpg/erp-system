# 개인 메일 연결 상태 복구 · 2026-11-20

- 최초 서버 조회 전에는 연결 여부를 알 수 없다. `loading / loaded / failed` 상태로 구분하고, 확인 전에는 채널·메일 설정·미확인 건수에 0개/미연결을 확정하지 않는다.
- 첫 조회 실패는 `조회 실패`와 재시도 버튼으로 안내한다. 기존 성공 데이터가 있으면 보존하며, 메일 확인 상태도 늦은 조회로 되돌아가지 않는다. 저장된 연결을 확인하기 전에는 계정 추가 폼을 열지 않는다.
- 운영 Gmail 수신 오류는 비활성 Gmail API였고, 실제 ERP OAuth 프로젝트를 확인하여 해당 API만 활성화했다. 기존 인증·읽기 범위·비밀키는 변경하지 않았다.
- API 복구 후 Gmail 접속은 성공했으나 기존 설정의 `ERP문의` 라벨이 없었다. 사용자가 라벨 방식 유지를 선택하여 본인 Gmail에 같은 이름의 빈 라벨을 만들었다. 임의 메일에 라벨을 붙이거나 전체 받은편지함을 가져오지 않았다.
- Gmail `ERP문의` 및 네이버 `INBOX` 모두 운영의 기존 수신 버튼으로 lastSyncedAt 갱신, 오류 해제를 확인했다. 원본 읽음·이동·삭제·발송은 하지 않았다. 빈 라벨의 0건은 연결 실패가 아니다.
- 개인 메일은 기존 소유자 범위로만 조회한다. 홈페이지 문의·내부 프로젝트 연락 기록과 권한을 합치지 않는다.
